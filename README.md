# Spatial-GUI For Wynncraft

A fork of Tastytrash's mod Spatial GUI made to work with custom server menus in Wynncraft!
Check out the original mod here: https://github.com/tastytrash/Spatial-GUI

## Dependencies

| Loader | Mod                   |
|--------|-----------------------|
| All    | YACL                  |
| Fabric | Fabric API & Mod Menu |
